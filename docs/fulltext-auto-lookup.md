# 全文自动查找与绑定

## 实施方案与范围

保留“全文查找绑定”的布局和现有后台任务框架。将独立下载工具中的多来源查找思路接入共享全文服务，增加 Semantic Scholar 标识符查找与 Crossref PDF 链接解析，沿用 Europe PMC、Unpaywall 和本地匹配。没有执行原工具、安装其 MCP 依赖或使用其个人路径、镜像下载目录。查询使用精确 DOI / PMID，不按相似标题猜测绑定。Crossref 的文本挖掘链接不等于开放下载许可，只提供来源链接。

## 存储与一致性

- `plat_fulltext_lookup_job`：项目、创建用户、幂等键、输入修订号、来源顺序与限额配置快照、任务状态、请求数、下载大小和时间。
- `plat_fulltext_lookup_item`：每篇文献的书目快照、输入版本、逐来源结果、状态和失败代码。
- `plat_fulltext_candidate`：候选来源、URL、许可、DOI、PMID、标题、匹配依据、错误和 provenance（来源标识符、内容版本、许可声明）。不覆盖原始书目。
- 共享 `FulltextAsset`：通过统一上传管线写入私有存储，记录 SHA256、下载最终地址、来源、候选与任务 ID、来源元数据、书目快照；复用安全校验、全文提取、配额和项目隔离。
- `RescreenFulltextBinding`：通过现有版本化绑定服务写入；标识符明确且唯一才能自动绑定，其他结果人工确认。重新查找保留历史记录。原文献或标准变动沿用现有失效规则及 QA 快照隔离。

无需新增数据表。0058 迁移补全候选和绑定来源的中文选项；不改历史迁移。

## 用户操作

1. 在全文绑定列表中勾选文献，可跨页保留选择；点击“批量在线查找”或“批量本地匹配”，按单次上限提交一个任务。也可使用每篇文献的单独操作。
2. 批量工具栏的“自动下载”控制整个批次；每篇操作栏的选项只控制单篇查找，二者独立，默认均勾选。取消后仅查询在线候选。
3. 提交后直接打开结果弹窗；“查找结果”只显示该文献的查找记录，含空状态。通过“本地选择”可绑定项目已有 PDF。
4. 每篇显示文献标题与状态，展开来源情况查看具体未找到或失败原因。下载失败可重试；无许可时查看来源页面或手动上传合法获取的 PDF。
5. 无 DOI / PMID 的文献不发起模糊网络搜索，显示明确提示并支持手动上传。

原工具中的镜像抓取与任意网页正则下载未接入：它们无法保证论文身份、来源许可或安全的文件处理；不绕过登录、验证码和来源访问限制。

## 配置与部署

执行 `python manage.py migrate` 后重启 Django、Celery Worker。在线查找作为内置功能始终可用，来源顺序由代码统一维护。

```ini
# 可选：Unpaywall 要求有效联系邮箱，未配置会跳过并给出提示。
FULLTEXT_UNPAYWALL_EMAIL=
```

新来源共用既有请求、时间、下载大小、每日预算、账户并发、磁盘配额及 SSRF 防护。不需要新增依赖或 API 密钥。来源可能限流、无开放全文或返回不可访问地址，不能保证每篇都下载成功。旧任务保持旧来源配置快照。

参考：[Semantic Scholar 官方 API](https://api.semanticscholar.org/api-docs/graph)、[Crossref 官方 REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)。
